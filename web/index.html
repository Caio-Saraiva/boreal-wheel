A new bridge for
an old companion.

Boreal Wheel reads the wheel through the system driver, adjusts axes in C and, on Windows, sends values to a virtual Xbox 360 controller created by ViGEmBus.

Wheel → Driver → Boreal Wheel → Game

If Windows does not recognize the device, the adapter has no inputs to translate. Check the Xbox 360 driver in Device Manager.

Demo mode lets you try the interface on Linux. The displayed time measures only C remapping; total latency depends on USB, the driver, the loop and the game.
