Boreal Wheel lê o volante pelo driver do sistema, ajusta os eixos em C e, no Windows, envia os valores para um Xbox 360 virtual criado pelo ViGEmBus.

Volante → Driver → Boreal Wheel → Jogo

Se o Windows não reconhecer o dispositivo, o adaptador ainda não terá entradas para traduzir. Verifique o driver Xbox 360 no Gerenciador de Dispositivos.

O modo Demo permite testar o visual no Linux. O tempo exibido mede apenas o remapeamento em C; a latência completa depende de USB, driver, loop e jogo.
